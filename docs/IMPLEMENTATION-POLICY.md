# Implementation and licensing boundary

This port is being implemented as a clean-room reimplementation from the feature requirements described by the user and the public Starling/Horizon native-mod interface.

Starling's contribution policy excludes reading, copying, adapting or paraphrasing LGPL-licensed project source. The upstream Effortless Building project is identified as LGPL-3.0-or-later, so this repository must not derive its implementation from the upstream Java source or decompiled classes. Feature names and high-level behavior requested by the user may guide an independent implementation; copied upstream code, translated algorithms, assets, or distinctive implementation details must not be included.

Before distributing a build, verify the upstream license and attribution independently and include the complete applicable license text only where legally appropriate. This file is an engineering boundary, not legal advice.
